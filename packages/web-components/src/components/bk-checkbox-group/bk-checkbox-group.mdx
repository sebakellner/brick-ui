## Horizontal

`orientation="horizontal"` flows the boxes in a row. Nothing else in the group's
layout changes with it.

<Canvas of={CheckboxGroupStories.Horizontal} />

## Required

`required` means **at least one box checked**. With nothing checked the group
reports `valueMissing` and the form refuses the submit; checking one box clears it
and unchecking the last one brings it back. The `*` is the mark; the requirement a
screen reader reads is the description text, because `role="group"` has no
`aria-required` — see the accessibility notes in the README.

<Canvas of={CheckboxGroupStories.Required} />

## Invalid

`invalid` paints the group's own label and leaves every box untouched: validity
stays each box's, and `required` on the group is the one constraint the group
itself enforces.
